# ReportsApp
Reports App for Constructions


## Προεπισκόπηση συνδέσμου (Open Graph)

Η προεπισκόπηση κοινοποίησης χρησιμοποιεί πλέον το νέο εικονίδιο **DP Construction** από το `assets/app-icon-512.png` του ίδιου repository, μέσω σταθερού απόλυτου HTTPS image URL, με Open Graph και Twitter/X metadata. Έχουν αφαιρεθεί τα παλιά στοιχεία `tiiny.host` / `tiiny.site` (συμπεριλαμβανομένων των περιττών scripts analytics/ads) που είχαν απομείνει μέσα στο HTML από προηγούμενο hosting.

Μετά τη δημοσίευση της νέας έκδοσης, εφαρμογές όπως WhatsApp, Viber, Messenger ή Facebook μπορεί να κρατούν παλιό preview στην cache τους. Επανέλεγξε το link μέσω Facebook Sharing Debugger ή δοκίμασε URL με νέο query parameter (π.χ. `?preview=dp2`). Αν το site είναι ακόμα σε παλιό hosting, πρέπει να δημοσιευτεί εκεί και η ενημερωμένη HTML.


## Όροι και τιμές (UI v5)

Τα πεδία «Τιμή μονάδας» **ξεκινούν κενά**. Υποστηρίζουν ποσά με ελληνικό κόμμα (`150,50`) ή τελεία (`150.50`) και ελληνικό διαχωριστικό χιλιάδων (`1.234,56`). Η τιμή δεν επαναμορφοποιείται όσο πληκτρολογείς, για να μη μετακινείται ο κέρσορας. Κενές/μη έγκυρες τιμές εμφανίζονται ως παύλα στο σύνολο γραμμής και στο PDF — **όχι ως 0 €**. Εφόσον έχουν εισαχθεί κάποιες αλλά όχι όλες οι τιμές, στο PDF εμφανίζεται «Σύνολο καταχωρημένων τιμών» και όχι τελικό συνολικό κόστος. Οι τιμές παραμένουν επεξεργάσιμες.

Οι γενικοί όροι απέκτησαν μεγαλύτερο, εύχρηστο checkbox, πλήρως πατήσιμο label με κατάσταση συμμετοχής στο PDF, καθαρότερη επεξεργασία κειμένων και πιο διακριτικό κουμπί αφαίρεσης. Τα κείμενα/labels της φόρμας χρησιμοποιούν πιο ήρεμη τυπογραφία, χωρίς υπερβολικά κεφαλαία. Η PWA cache έγινε v5 για εγκατεστημένες συσκευές.
