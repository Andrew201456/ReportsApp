# ReportsApp
Reports App for Constructions


## Προεπισκόπηση συνδέσμου (Open Graph)

Η προεπισκόπηση κοινοποίησης χρησιμοποιεί πλέον το νέο εικονίδιο **DP Construction** από το `assets/app-icon-512.png` του ίδιου repository, μέσω σταθερού απόλυτου HTTPS image URL, με Open Graph και Twitter/X metadata. Έχουν αφαιρεθεί τα παλιά στοιχεία `tiiny.host` / `tiiny.site` (συμπεριλαμβανομένων των περιττών scripts analytics/ads) που είχαν απομείνει μέσα στο HTML από προηγούμενο hosting.

Μετά τη δημοσίευση της νέας έκδοσης, εφαρμογές όπως WhatsApp, Viber, Messenger ή Facebook μπορεί να κρατούν παλιό preview στην cache τους. Επανέλεγξε το link μέσω Facebook Sharing Debugger ή δοκίμασε URL με νέο query parameter (π.χ. `?preview=dp2`). Αν το site είναι ακόμα σε παλιό hosting, πρέπει να δημοσιευτεί εκεί και η ενημερωμένη HTML.
